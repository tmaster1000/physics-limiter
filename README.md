This mod turns cars outside your configured range to “stand-ins”: lightweight copies with physics turned off. Stand-ins have simulated suspension, engine sound, effects, and BeamMP position sync. Damage is not shown on them, because drawing it would freeze the game for a moment. When a stand-in switches back to a full vehicle, any damage it took over the network in the meantime is applied.
