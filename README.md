The mod adds "stand-ins"/fake vehicles with disabled physics configurable with the above settings. The stand-ins have simulated suspension, sound, effects and BeamMP position & damage sync. Local damage is not visible on the stand-ins, as that would require a brief pause for the game, but if the stand-in is turned into a physical vehiclee, damage it has received over the network before that point is applied.
